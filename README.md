# Delo z besedilom in drsnim pogledom – ScrollingText

## Opis projekta
Aplikacija ScrollingText prikazuje daljše besedilo članka v drsnem pogledu. Uporabniški vmesnik je razdeljen na dva stolpca: levi stolpec širine 100dp prikazuje podnaslov, desni stolpec pa glavno besedilo članka.

## Funkcionalnosti
- Prikaz podnaslova v levem stolpcu.
- Prikaz glavnega besedila v desnem stolpcu.
- Navpično drsenje po daljšem besedilu z uporabo gradnika `ScrollView`.
- Vodoravna razporeditev stolpcev z uporabo `LinearLayout`.
- Gumb, ki ob kliku prikaže sporočilo `Comment submitted!` z uporabo gradnika `Toast`.

## Uporabljene tehnologije
- Android Studio
- Java
- XML
- `TextView`
- `ScrollView`
- `LinearLayout`
- `Toast`

## Uporabljeni viri
Besedila naslovov, podnaslovov in članka so shranjena v datoteki `strings.xml`.
